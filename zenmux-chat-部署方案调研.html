ZenMux 个人对话站 · 部署方案调研

目标：个人自用、类 ChatGPT UI 的极简对话网站，后端调用 zenmux.ai 聚合大模型 API
调研日期：2026-08-31 ｜ 所有价格标注了来源与性质（刊例价 / 活动价）

一、结论先行

推荐：首选 静态托管 + 边缘函数反代（Serverless），月成本 ¥0

具体选型：腾讯云 EdgeOne Pages 国际版（edgeone.ai）。免费、不限流量与请求数、无需 ICP 备案、自带 HTTPS 与自定义域名、内置边缘函数与 KV 存储。

次选：阿里云 ESA Pages，能力几乎等价（无限流量、边缘函数 10 万请求/天）。选它主要因为账号已在阿里云生态。

不建议为这个需求买云服务器跑 Docker。这个场景（无状态、纯转发、单人低频）是 Serverless 的最佳击球点，固定月租 + 系统/证书/容器运维是纯浪费。

一句话理由

ZenMux 的 API 对任意来源返回 access-control-allow-origin: *（我已实测），浏览器可直连并流式读取；你真正需要服务器的原因只剩两个——网络不通 或 不想把 API Key 暴露在前端。这两件事边缘函数都能解决，且免费。

二、必须先验证的两个前提（决定方案分支）

1. ZenMux 的 CORS 策略 —— 已实测，通过

$ curl -i -X OPTIONS https://zenmux.ai/api/v1/chat/completions \
    -H "Origin: https://example.com" \
    -H "Access-Control-Request-Method: POST" \
    -H "Access-Control-Request-Headers: authorization,content-type"

HTTP/2 204
access-control-allow-origin: *
access-control-allow-headers: *
access-control-allow-methods: OPTIONS,POST
access-control-expose-headers: X-ZenMux-RequestId
server: cloudflare

含义：任何来源的网页都能用 fetch POST 到 ZenMux 并读取响应流（SSE 流式可用）。技术上，纯静态页面零后端即可跑通完整对话体验。

2. ZenMux 从你的网络能否直连 —— 需你自己验证

ZenMux 位于 Cloudflare 之后。多家中文评测称"国内直连可用、无需特殊网络"，但 Cloudflare 在中国大陆的可达性本身波动较大，且 我这台机器出网走了代理，无法代表你的网络环境。请花 30 秒自测：

# 在你的终端（不开代理）执行
curl -s -o /dev/null -w "%{http_code} %{time_total}s\n" https://zenmux.ai/api/v1/models

# 更直接：浏览器（无代理模式）打开
https://zenmux.ai/api/v1/models
  • 返回 200 且 < 2 秒 → 走方案 A（纯静态直连），零后端，10 分钟上线。
  • 超时 / 证书错误 / 很慢 → 走方案 B（边缘函数反代），仍然 ¥0。

四、方案详解

方案 A｜纯静态 + 浏览器直连（最快验证）

形态：一个 index.html，用 OpenAI JS SDK（dangerouslyAllowBrowser: true）或裸 fetch 读 SSE 流。

const r = await fetch("https://zenmux.ai/api/v1/chat/completions", {
  method: "POST",
  headers: { "Content-Type":"application/json",
             Authorization: `Bearer ${localStorage.getItem("zenmux_key")}` },
  body: JSON.stringify({ model:"openai/gpt-5", messages, stream:true })
});
// 用 r.body.getReader() 逐 chunk 解析 SSE 渲染

风险与对冲：Key 会出现在浏览器内存与 DevTools 里，任何装了你页面上的第三方脚本都能读走。对冲手段（ZenMux 官方支持，非我推测）：

  • 为这个页面单独建一个 API Key，打 tag 标记 frontend；
  • 在该 Key 上开启 Credit Limit（比如 $10 硬顶）+ RPM/TPM 限额；
  • 用 Supported Models 白名单锁定到 2–3 个你真用的模型。

ZenMux 控制台 → Pay As You Go API Keys → 创建时可配 Credit Limit / Credit Threshold / RPM / TPM / Supported Models，并可一键 Enable-Disable。

方案 B｜EdgeOne Pages 免费版 + Pages Functions 反代 推荐

形态：functions/api/chat.ts 一个函数，读环境变量里的 Key，转发到 ZenMux 并把 SSE 流原样透回。

EdgeOne Pages 免费版额度（官方定价页）：

  • 安全加速流量与请求数 —— 不限量
  • Edge Functions：300 万次请求/月 + 300 万 CPU 时间/月
  • Cloud Functions：100 万次请求/月 + 50 万 GBs/月
  • KV 存储：1 GB ｜ 构建次数：500 次/月

个人对话场景（假设每天 100 轮，每轮 1 次函数调用）月耗约 3,000 次 —— 用到免费额度的 0.1%。

为什么是国际版（edgeone.ai）而不是国内版：

国内版（edgeone.cloud.tencent.com）国际版（edgeone.ai）
自定义域名需 ICP 备案无需备案
CDN 节点含国内节点，国内最快仅海外节点，国内"还行"（多份实测优于 Vercel / CF Pages / GitHub Pages）
注册腾讯云账号邮箱 + GitHub，无需信用卡/手机

限制：每个账号所有项目总大小 ≤ 5 GB；目前主要支持绑定 GitHub。官方声明免费版"将永久提供"，但商业化后可能加限制。

续费陷阱（务必核对）：国内云长期策略是"首年低价、次年翻数倍"。腾讯云有 99 元/年 的境外轻量活动（香港/新加坡/东京），但那是首年；阿里云 ¥39/月 是活动价，国际站刊例是 $15/月。下单前在结算页确认"续费价格"，别只看首购价。

Docker 在这里的定位：docker compose 跑两个容器（前端 Nginx 静态站 + Node 反代，或一个 Next.js 容器搞定）+ Caddy 自动 HTTPS。2 GB 内存起步比较稳，1 GB 跑 Node + Caddy 勉强。

真正的成本不是钱，是运维：系统补丁、Docker/镜像升级、证书续期、日志盘、被扫端口。个人自用场景下这些全是净支出。

方案 D｜函数计算 FC / 云函数 SCF

阿里云 FC 新用户每月 100 万次调用 + 40 万 GB-秒免费额度（6 个月），之后按 CU 计费（阶梯一 ¥0.000088/CU）。个人用量大概率长期落在免费额度内。

但复杂度明显更高：需要配 HTTP 触发器 + 自定义域名（国内 region 的域名要备案，香港 region 不用）、冷启动（Node 数百毫秒，Python 更慢）、流式响应需确认支持。同样的钱（¥0）和更少的事，方案 B 全都能做到，且还自带前端托管与全球 CDN。除非你有别的原因必须用 FC，否则跳过。

六、落地路径建议

  1. 先做前提验证（5 分钟）：不开代理，浏览器打开 https://zenmux.ai/api/v1/models。
  2. 通 → 方案 A：单个 HTML 文件，部署到 EdgeOne Pages 国际版（或用 Pages Drop 直接拖文件，单文件限 25 MB）。10 分钟可访问。
  3. 不通，或介意 Key 暴露 → 方案 B：加一个 functions/api/chat，前端改调 /api/chat。Key 挪进环境变量。
  4. 需要持久化会话历史 / 多设备同步：方案 B 基础上加 KV 存储（EdgeOne Pages 免费 1 GB）存会话；再复杂才考虑升到方案 C。
  5. 只有当你明确想要一台境外服务器（顺带做别的用途）时，才回到方案 C，选腾讯云香港锐驰型 2C2G ¥55/月（无限流量，刊例价，续费不涨价）。

七、坑与不确定性（诚实标注）

  • SSE 流式透传未实测。方案 B 依赖边缘函数能原样透传 text/event-stream。EdgeOne Pages Functions 与 ESA 边缘函数均基于 V8 isolate 运行时，理论上支持 ReadableStream 透传，但我没有实机验证过流式场景。建议先写一个最小函数验证流式，再投入写 UI。若不支持，回退：关闭流式一次性返回（体验降级），或改走方案 C。
  • "国内直连"是二手结论。ZenMux 走 Cloudflare，中文评测说国内可用，但 Cloudflare 在大陆的可达性本身波动大，不同运营商/省份差异明显。这是整个方案里最大的单点不确定性，务必自测。
  • EdgeOne Pages 免费版的长期性。官方措辞是"免费版本将永久提供，但商业化后可能有一定限制"。做好随时可迁移的准备（代码就是个静态站 + 一个函数，迁移成本极低）。
  • 价格随时变动。文中腾讯云价格来自 2025-09-15 与锐驰型套餐的官方公告，阿里云价格混合了活动价与国际站刊例，性质已在表中标注。下单当天以结算页为准。
  • 轻量服务器的"峰值带宽"不是承诺值，是上限。200 M 峰值对个人对话站绰绰有余。
  • 香港/新加坡服务器免 ICP 备案，这是选境外地域的核心理由之一 —— 若你选国内版 Pages 或大陆地域服务器，自定义域名必须备案。
